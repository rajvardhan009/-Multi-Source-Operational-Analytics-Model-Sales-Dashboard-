# Operational Analytics Dashboard

This project demonstrates the ability to analyze large-scale, time-based operational data using structured data modeling, DAX-driven insights, and multi-dimensional visualization techniques.  
Although based on retail sales transactions, the analytical structure mirrors real-world system monitoring workflows used in scientific and technical environments.

## Project Overview
This dashboard simulates an Operational Monitoring System capable of:
- Tracking high-frequency events over time
- Comparing performance across time windows
- Identifying anomalies and unusual spikes
- Integrating multiple data sources into a unified analytical model
- Presenting KPIs for system health

## Analytical Capabilities
- **Event Monitoring:** Trend analysis and peak detection
- **System Metrics:** Profit ↔ Net Sales correlation, event density
- **Comparative Insights:** Dual-period comparison
- **Exploration:** Detailed filtering across dimensions

## Data Model
Star schema with:
- Fact Table
- Dim Customer
- Dim Product
- Dim Promotion
- Two Date Tables
- Measures Table

## Tools Used
Power BI, DAX, Power Query, Excel
